# 🏠 The Second Home – Smart Hostel Management System

A role-based Hostel Management System built to digitize hostel operations and simplify communication between students and wardens. The application automates room allocation, hostel applications, complaint management, and mess menu updates through a secure web interface.

## 🚀 Tech Stack

- **Backend:** Java, Jakarta Servlets, JSP, JDBC
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Server:** Apache Tomcat
- **Architecture:** MVC

## ✨ Features

### Student
- Hostel room application
- Track application status
- View allocated room details
- Raise and track complaints
- View mess menu
- Manage profile

### Warden
- Approve/reject applications
- Allocate hostel rooms
- Manage student records
- Resolve complaints
- Update mess menu
- Monitor room availability

## 🔒 Highlights

- Role-based authentication
- Session management
- CRUD operations
- JDBC-MySQL integration
- MVC architecture
- Secure and modular design

## 🛠️ Getting Started

1. Clone the repository.
2. Import the MySQL database.
3. Configure JDBC credentials.
4. Deploy on Apache Tomcat.
5. Run the project.
